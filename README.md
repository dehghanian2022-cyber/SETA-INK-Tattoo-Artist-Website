# SETA INK — Tattoo Artist Website

SETA INK is a modern and responsive promotional website I designed and developed for my Iranian friend, Setayesh, who is beginning her journey as a tattoo artist.

The website was created to showcase her tattoo work, introduce her artistic style, present her services, and make it easy for potential clients to contact her through Instagram.

## ✨ Features

- 🎨 Modern dark tattoo-inspired design
- 📱 Responsive layout for desktop, tablet, and mobile
- ✨ Animated intro screen
- 🖼️ Tattoo portfolio section
- 🖋️ Tattoo styles section
- 💼 Services page
- 👤 About section
- 🌱 My Journey section
- ❓ Frequently Asked Questions
- 📩 Instagram contact section
- 🌍 English and Persian content
- 🎯 Simple and user-friendly navigation

## 🎨 Design

The website uses a dark and elegant color palette inspired by tattoo studios:

- Black — `#0D0C0C`
- Warm Beige — `#E9E0D4`
- Burgundy — `#6E2637`
- Dark Card — `#171515`

The **Cinzel** font is used for the main headings and branding to create an elegant and artistic look.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
